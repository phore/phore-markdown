# AI Usage Info

## Purpose

Phore Markdown provides deterministic conversion between a deliberately small Markdown subset and HTML, plus safe HTML-to-text fallback.

## Security boundary

Treat all source strings as untrusted. HTML-to-Markdown removes active or externally loaded elements; Markdown-to-HTML escapes raw HTML and rejects unsafe link schemes.
